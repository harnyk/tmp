# assets/

## head.png — голова Алисы (опционально)

Слот для «прифотошопленной» головы. Положи сюда файл **`head.png`**:

- прозрачный фон (PNG с альфой);
- в кадре — только голова/лицо, примерно квадрат;
- любой размер — движок сам масштабирует под плечи человечка.

Игра загружает `assets/head.png` при старте. Если файла нет (или браузер не дал
его прочитать по `file://`) — тихо рисуется голова-плейсхолдер, ошибок нет.

Хочешь заменить — просто положи новый `head.png` и перезагрузи страницу.

## kobra.png — лицо Кобры Орват (опционально)

Слот для лица Кобры Орват (по замыслу — Дарья Верещагина). Те же правила:
прозрачный фон, только голова/лицо. Подставляется в капюшон Кобры у лифтов;
нет файла — рисуется плейсхолдер (блондинка-каре).
