# Алиса и роутеры 📶

Мобильный веб-платформер: человечек из линий (Алиса Селезнёва) идёт по
**бесконечному больничному коридору** — каталки, двери с табличками, лифты,
абсурдные плакаты на стенах, зелёная полоса-отбойник — и собирает **Wi-Fi
роутеры**.

**Цель — «Апофеоз войны» из роутеров.** Рюкзак вмещает максимум **16** роутеров
(счётчик — квадрат 4×4, полный горит золотом). Набрала — доносишь до **лифта** и
**свайпом вниз** проваливаешься в **Апофеозошную**: АС стоит на трамплине над
пирамидой и вываливает роутеры в кучу. Пирамида **растёт всю сессию** (прогресс
сохраняется в браузере) — строим гору роутеров, как черепа у Верещагина.

Некоторые лифты стережёт **Кобра Орват** — кобра с девичьим лицом (застывшее
S-тело, капюшон). Это таможня: при выгрузке она берёт «пошлину» 1–2 роутера,
остальное уходит в пирамиду.

**Злой Близнец.** Кобра — это повзрослевшая, «неправильная» Алиса. Если прийти к
её лифту с **полным** рюкзаком (16) и уйти, **не заплатив**, происходит
**рокировка**: Алиса остаётся привратницей, а ты играешь **за Кобру** — коридор
чернеет, вспыхивают красные огни, лифты горят адским пламенем. Твои 16 сгорели;
теперь надо набрать 16 заново и сбросить их во **ТЬМУ** (пирамиде не идут). После
этого — возврат к Алисе. Так Злой Близнец забирает твою жизнь.

Движок — **[Phaser 3](https://phaser.io/)** (грузится с CDN). Никаких сборок и
зависимостей: вся графика рисуется кодом, звук — WebAudio. Одна страница
`index.html`.

## Как запустить

**С телефона** проще всего — открыть живую версию (Artifact-ссылка в чате).

**Локально:**

```bash
# просто открой index.html в браузере, либо подними статику:
python3 -m http.server 8099
# затем открой http://localhost:8099/index.html
```

> Если открывать `index.html` двойным кликом (протокол `file://`), картинка
> головы из `assets/head.png` может не подгрузиться из-за политики браузера —
> тогда рисуется голова-плейсхолдер. Через `http://` всё работает.

## Управление

| Действие | Телефон (жесты) | Клавиатура |
|----------|------------------|------------|
| Идти влево/вправо | **свайп-и-держи**: тяни палец в сторону и держи — идёт, пока держишь; отпустил — стоп | `←` `→` или `A` `D` |
| Прыжок | **свайп вверх** (быстрый флик) | `↑`, `W` или `Пробел` |
| Прыжок в сторону | свайп вверх во время ходьбы (или диагональный флик вверх-вбок) | направление + прыжок |
| Выгрузить рюкзак | **свайп вниз** стоя у лифта (появится подсказка) | — |

Мультитач: можно держать направление одним пальцем и фликнуть вверх вторым —
прыжок сохранит направление. Ходить можно в обе стороны — коридор бесконечен.

## Голова Алисы (замена картинки)

Голова берётся из `assets/head.png` (спрайт на прозрачном фоне) и сама встаёт на
плечи человечка; при ходьбе зеркалится по направлению движения. Чтобы заменить —
положи свой PNG на прозрачном фоне в `assets/head.png` и перезагрузи страницу
(размер подгоняется автоматически).

Файла нет → тихо используется нарисованный плейсхолдер, игра не ломается.

## Что дальше (идеи)

Пока это весь скоуп. Легко нарастить: врагов/препятствия с проигрышем, бонусы,
уровни сложности (рост скорости), рекорд в `localStorage`, звук-эмбиент.

## Структура

```
index.html        — вся игра (Phaser + графика + управление + коридор)
assets/head.png   — (опционально) голова Алисы; слот с фолбэком
```
